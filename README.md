# Raquel Susko | Robotics Hardware Portfolio

Welcome to my professional portfolio repository. I am an Electrical Engineering student at **Texas A&M University** pursuing a concurrent **B.S. (May '27)** and **M.S. (Dec '27)**. 

This repository contains the source code for my personal portfolio website, which showcases my work in robotic hardware &mdash; custom PCB design, embedded firmware, and mechatronic integration &mdash; alongside prior research in autonomous systems and Vision-Language-Action (VLA) models.

## 🛠 Technical Stack
* **Embedded Systems:** Altium Designer (Custom PCB), STM32 (C/C++), I²C, SPI, DMA, Jetson Nano.
* **Mechatronics:** Servo & actuator control, EMG signal acquisition, PID control, sensor integration.
* **AI & Robotics:** ROS 2 (Humble/Galactic), Lerobot, SmolVLA, ACT, DAgger, PyTorch, TensorFlow.
* **Web Development:** HTML5, CSS3 (Custom Responsive Framework), JavaScript.
